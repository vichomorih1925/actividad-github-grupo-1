# Calculadora de precios

Actividad práctica para aplicar un flujo básico de trabajo colaborativo utilizando:
- Git mediante línea de comandos
- GitHub mediante interfaz web
- Ramas de desarrollo (Branches)
- Pull Requests
- GitHub Actions (Validación automática de sintaxis)
- Code Review (Revisión y comentarios de código)
- Merge hacia la rama principal

## Integrantes y Roles

- **Matthias Garrido**: Revisor / Code Reviewer (revisión de Pull Request, comentarios técnicos, solicitud de cambios y aprobación)
- **Gonzalo Guerra**: Encargado de GitHub Actions (configuración de workflows y validación continua)
- **Cristian Aravena**: Documentación y Evidencias (registro de capturas y consolidación del informe)

## Descripción del Proyecto
Pequeña aplicación desarrollada en Python que calcula el valor total de una compra y permite la aplicación dinámica de descuentos porcentuales.
